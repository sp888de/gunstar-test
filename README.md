# GUNSTAR — site de test

Copie de gunstaz/www issue de l’archive fournie. Ce dépôt est destiné aux tests et ne configure aucun déploiement vers le site de production.

Le dossier privé, les clés Stripe, les commandes, la base de données et les fichiers propres à OVH sont exclus. Aucun domaine personnalisé n’est défini dans ce dépôt.

GitHub Pages sert les pages HTML, CSS, JavaScript et les médias. Les fichiers PHP sont conservés comme code source mais ne sont pas exécutés par GitHub Pages : le stock et les paiements nécessitent un serveur PHP séparé. Le formulaire de contact conserve son service externe existant.

Attention : le domaine personnalisé du site GitHub Pages principal peut être hérité par les sites de projet. Vérifier l’URL de publication avant utilisation.
